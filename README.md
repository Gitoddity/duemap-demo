# DueMap showcase

Public demo frontend for DueMap. Open the [showcase](https://gitoddity.github.io/duemap-demo/).

Profiles are temporary. Use Export Profile to download your changes, then import the JSON file next time. The API runs on Render Free and may take about a minute to wake up.

This repository contains only built browser assets. The application source is maintained separately. Provider attribution is in `providers/README.md`.
