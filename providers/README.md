# Provider assets

Bundled locally; no browser request is made to a logo CDN.

- `klarna.svg`, `paypal.svg`, `afterpay.svg`: Simple Icons, retrieved from
  https://github.com/simple-icons/simple-icons/tree/develop/icons.
  The library license is retained in `SIMPLE-ICONS-LICENSE.md`.
- `sezzle.svg`: unmodified Color Logo from Sezzle's official logo bundle,
  linked at https://sezzle.com/en-ca/brand-assets/.
- `affirm.png`: icon served by https://www.affirm.com/ at
  https://images.ctfassets.net/4rc1asww3mw7/12w7jdl0M43WqtLY7eFx3U/d70a2b87ecac8188f884d7c62d88a3b9/affirm-icon.png.

Brand marks identify the saved plan's provider. Provider names remain visible
beside decorative images for accessibility. The marks belong to their respective
owners; the icon library license does not grant trademark rights.
